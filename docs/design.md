# Orca Monitor visual contract

Use Omarchy's native KeyboardPanel positioning and WidgetButton, but match Orca's sidebar inside the popup: Geist type, source-derived agent/provider logos and Lucide interface icons, with backgrounds and UI colors supplied by Omarchy's active theme. Operate mode: scan sessions quickly, then jump to a workspace. Fonts and assets are bundled locally; no system font or theme settings are changed.

Orca's own sidebar is the layout reference. Project headings sit above subtly outlined workspace cards. Each workspace is one hoverable, clickable, keyboard-selectable card; individual agents have no hover or click treatment. All agent rows remain visible as compact single-line status glyph / provider logo / task / time summaries. Titles are 13px, compact agent text 11px, timestamps 10px, and agent rows 24px. Show the outlined 16px primary badge only when the CLI explicitly reports the main worktree. Sort projects, workspace cards, and agent rows by recent activity, latest to oldest. Workspace activity is the newest valid Orca workspace activity/output or agent update timestamp; projects follow their newest workspace. Equal timestamps use deterministic name/identity ordering. Card activation opens a live, selectable waiting agent when the workspace needs attention; otherwise it opens the most recently active live, selectable agent. Never substitute a working agent when all waiting targets are unavailable. Waiting cards use an urgent-tinted outline and a readable Needs you label without changing recent-activity order. Active workspace gets a quiet foreground tint and outline; inactive cards have no outline until hovered or selected. Working state ports Orca's 8px/6px ring in the theme accent color with twelve rotation steps per second; stop rotation when hidden or stale and show a complete static ring under reduced motion. Workspace completion is an accent-colored dot; agent completion uses Orca's Lucide circle-check. Attention uses the theme urgent color and neutral states use muted. In the bar, attention takes priority over concurrent working activity. The logo toggles the popup; the separate status hit target jumps to the most recent live waiting session, or opens the popup when that target is unavailable. Both targets retain middle-click refresh and accessible keyboard actions. Monochrome glyphs follow theme ink while colored provider logos keep their brand colors. The native popup supplies its own themed surface, including transparency; do not overlay another hardcoded or duplicated background. Source provenance and licenses are recorded in docs/asset-sources.md. Attention still takes priority when deriving each workspace's status indicator, independently of recent-activity ordering; text and symbols carry meaning without color alone. Scroll the list; never hide sessions behind expansion controls.

Use plain text for all external labels, ellipsis for long rows, visible keyboard selection, and useful connecting, unavailable, stale and empty states. Do not add dashboard headings, a session-count subtitle, footer instructions, placeholder actions or decorative animation beyond the functional pending indicator. Keep diagnostic errors and stale/empty states available.
